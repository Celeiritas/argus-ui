# Sounds (not included)
The page plays these if they exist, and stays silent if they don't:
- `freeze.mp3` – Medusa turns a task to stone
- `thaw.mp3` – the stone crumbles
- `bolt.mp3` – Zeus's lightning strike

Put your own sound files here (with the right to use them) before running `scripts/build.sh`.
Keep each one around 2–4 seconds. This folder's mp3 files are ignored by git.
